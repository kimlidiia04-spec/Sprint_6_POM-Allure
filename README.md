Автотесты на Selenium для Яндекс.Самокат
Автоматизированные UI-тесты для учебного тренажёра «Яндекс.Самокат» (https://qa-scooter.praktikum-services.ru/), написанные на Python с использованием Selenium и pytest.

Что протестировано
Заказ самоката — полный позитивный сценарий оформления заказа, проверен с двумя разными наборами тестовых данных:
-Вход в сценарий через обе точки входа: кнопка «Заказать» в шапке сайта и кнопка «Заказать» внутри формы.
-Заполнение формы: имя, фамилия, адрес, станция метро, телефон.
-Заполнение второго шага: дата доставки, срок аренды, цвет самоката, комментарий для курьера.
-Подтверждение заказа и проверка всплывающего окна с сообщением «Заказ оформлен».
-Переход к статусу заказа.
-Проверка перехода на главную страницу по клику на логотип «Самокат».
-Проверка перехода на главную страницу Дзена (в новой вкладке, через редирект) по клику на логотип Яндекса.

Блок вопросов и ответов (FAQ) — для каждого из 8 вопросов на главной странице проверяется, что при раскрытии аккордеона отображается корректный текст ответа. Тест параметризован восемью наборами данных (вопрос → ожидаемый текст ответа).

Структура проекта
pages/base_page.py — базовый Page Object: общие методы ожидания и взаимодействия с элементами (клик, ввод текста, получение текста, ожидание видимости, переключение окон).
pages/main_page.py — Page Object главной страницы (кнопки заказа, логотипы, подтверждение cookies).
pages/order_page.py — Page Object формы заказа (поля ввода, выбор даты и срока аренды, выбор цвета самоката, подтверждение заказа).
tests/test_order.py — параметризованный тест позитивного сценария заказа, два набора данных.
tests/test_faq.py — параметризованный тест блока вопросов и ответов на главной странице, восемь наборов данных.
